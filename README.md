# 史永琴 · 数据产品 / 策略产品作品集

## 发布到 GitHub Pages

1. 新建公开仓库，建议命名 portfolio。
2. 把本文件所在目录中的所有内容上传到仓库根目录，确保 index.html 位于根目录。
3. 不要直接上传 ZIP 文件；请先解压，再上传文件和 assets 文件夹。
4. 进入仓库 Settings → Pages。
5. Source 选择 Deploy from a branch；Branch 选择 main；Folder 选择 / (root)；点击 Save。
6. 等待发布完成，在 Pages 设置中点击 Visit site。

默认网址：https://shiyongqin.github.io/portfolio/

## 文件说明

- index.html：页面内容
- styles.css、career.css：桌面和手机布局
- app.js：岗位切换、截图展示、弹窗和链接复制
- assets/：截图、简历和产品作品集
- .nojekyll：禁用 Jekyll 处理，直接发布静态文件

网站可独立运行，不需要额外安装依赖。联系方式和简历文件沿用已确认的个人网站内容。
