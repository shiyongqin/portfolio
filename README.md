# 史永琴 · 数据产品 / 策略产品作品集

以百度网盘、快手 Kwai 和 Terabox 项目，展示数据分析、策略设计和实验验证能力。

## GitHub Pages

网站地址：https://shiyongqin.github.io/portfolio/

进入 Settings → Pages，Source 选择 Deploy from a branch，Branch 选择 main，Folder 选择 / (root)，点击 Save。

## 文件结构

- index.html：作品集页面
- styles.css、career.css：响应式布局与视觉样式
- app.js：岗位阅读入口、真实截图展示与个人速览
- assets/：产品界面截图与图标
- .nojekyll：直接发布静态文件

本仓库包含网页、图片素材及公开下载的校招简历。
